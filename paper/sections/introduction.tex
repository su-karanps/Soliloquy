\section{Introduction}

Language models can produce fluent factual answers while being wrong and highly
confident. This project asks whether a model's hidden states contain an internal
correctness signal that differs from outward confidence signals such as token
log-probability, entropy, margin, and verbalized confidence.

The core distinction is between decodability and causality. A signal is
decodable if a probe can read it from activations. A signal is causal if changing
the relevant activation changes the model's answer-selection behavior.
